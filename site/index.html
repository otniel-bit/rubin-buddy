Rick

An 8-bit buddy who sits on your screen while you work.

He watches what Claude Code is doing. Now and then he says something.

Install

  1. Press ⌘ Space, type Terminal, press return.
  2. Paste the line below.
  3. Press return.
curl -fsSL https://raw.githubusercontent.com/otniel-bit/rubin-buddy/main/install.sh | sh

It takes about a minute. He appears in the bottom-right corner.

That's all

Settings are in the menu bar — the small bald head. Size, how often he speaks, and Bring Him Back if you ever lose him.

He keeps himself up to date.

If it asks for the Xcode Command Line Tools

Paste this instead, let it finish, then paste the install line again.

xcode-select --install

To make him follow Claude Code

If Claude Code is on your Mac, the installer asks. Say yes.

Otherwise — or if you skipped it — click the bald head in the menu bar: Follow Claude Code.

He thinks while it thinks, works while it works, and nods when it's done. Works with Claude Code anywhere it runs — the terminal, the Claude desktop app, and Cowork.

macOS. Nothing runs as administrator. Built from source on your own machine, so there's nothing unsigned to talk your way past. One command removes him completely: ~/.rubin-buddy/uninstall.sh
